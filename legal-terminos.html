El sitio www.inkamaps.com (el «Sitio») es propiedad de InkaMaps y está operado por InkaMaps («InkaMaps» o «nosotros»). Al usar el Sitio, el mapa, las API o el contenido que ponemos a su disposición a través de ellos (en conjunto, los «Servicios»), usted acepta quedar obligado por estos Términos de servicio, en su versión vigente (los «Términos»). Léalos con atención: si no está de acuerdo, no podrá usar los Servicios.

Registro

  • Puede ver el mapa y buscar sin cuenta, con límites diarios. Para usar más, construir sus propias capas (Builder) u obtener API keys necesita una cuenta de InkaMaps. Cada solicitud a una API debe incluir una de las API keys de su cuenta.
  • Cuide la seguridad de su cuenta y controle el uso de sus API keys. Usted es responsable de todo uso de los Servicios con su cuenta, autorizado o no, incluido el uso de sus keys. A nuestro criterio, podemos hacer excepciones limitadas si nos avisa del problema con prontitud.
  • Debe tener 18 años o más para usar los Servicios. Al registrarse o darnos información personal, usted declara tener al menos 18 años.
  • Si acepta estos Términos en nombre de su empresa u otra entidad, declara tener autoridad para obligarla, y «usted» significa esa entidad.

Nuestros servicios

Pondremos los Servicios a su disposición conforme a nuestro Acuerdo de nivel de servicio cuando su plan lo incluya. Sujeto a estos Términos, le otorgamos una licencia no exclusiva y revocable para:

  • Usar los Servicios para desarrollar servicios en línea y aplicaciones web, de escritorio o móviles.
  • Poner los Servicios a disposición de sus usuarios finales como parte de esos servicios y aplicaciones.

Puede usar los Servicios en aplicaciones comerciales y no comerciales dentro de los límites de su plan. Para usos fuera de esta descripción —por ejemplo, procesar por lotes bases completas de direcciones, aplicaciones con volúmenes mayores o medios impresos masivos— contáctenos para un plan Enterprise.

API de Geocoding y Autocompletado

  • Puede guardar los resultados de Geocoding (coordenadas, ubigeo y dirección normalizada) junto con los registros de su propia aplicación, para su propio uso. No puede revender ni redistribuir esos resultados a terceros, salvo a sus usuarios finales como parte integrada de su aplicación.
  • No puede usar los resultados de Geocoding ni de Autocompletado para:
    • Crear una base de datos general de ubicaciones o direcciones de un barrio, ciudad, región o país, ni ninguna otra base de datos cartográfica de uso general.
    • Desarrollar o probar otro servicio o API de geocodificación.
  • No puede usar los resultados de lugares (Places) para:
    • Generar prospectos de venta, segmentar anunciantes o hacer análisis publicitario;
    • Crear o enriquecer perfiles de usuarios o segmentos de audiencia;
    • Enviar alertas en tiempo real o contenido personalizado según la cercanía del usuario a un lugar (geovallas). Mostrar contenido en respuesta a búsquedas o a la interacción con el mapa no se considera geovalla.
  • El procesamiento masivo de bases de direcciones (por lotes) requiere un plan Enterprise.
  • Con aviso por escrito, podemos verificar su uso de las API para asegurar que cumple esta sección.
  • Para otros casos de uso o derechos adicionales, contáctenos por un plan Enterprise.
