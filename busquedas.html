Geocoding

Dirección ↔ coordenada, como se escribe en el Perú

De dirección a punto y de punto a dirección, con ubigeo, manzana y lote. Responde en el formato de Geodir, así que migrar es cambiar la URL y la key.

  • Entiende “Jr.”, “Psje.”, “Mz. B Lt. 12”, AA.HH. y referencias.
  • Geocodificación inversa con distancia y nivel de confianza.

Autocompletado

Búsqueda mientras escribes

Sugerencias de direcciones y lugares letra por letra, para tus formularios de registro, checkout y buscadores.

  • Prioriza resultados cerca del usuario o en un distrito.
  • Tolera tildes, abreviaturas y errores de tipeo.
  • Menos direcciones mal escritas, menos entregas fallidas.

API y consola

Para desarrolladores, desde el primer día

Una key por sistema, consola para crear y revocar keys, probar las APIs y ver tu consumo día a día.

  • API REST en JSON, autenticada con el header x-api-key.
  • Si una key se filtra, revocas solo esa.
  • Consumo por API y por día, con precios en soles.
  • Documentación y ejemplos en español.
